CONFIGURATION (Optional)
───────────────────────────────────────────────────────────────────────────

The tools will work with default URLs, but you can customize by adding to .env.local:

# Netra (optional - has defaults)
NETRA_BASE_URL=http://netra.internal.dish.com/api
NETRA_API_KEY=your_api_key_here

# Grasshopper (optional - has defaults)
GRASSHOPPER_BASE_URL=http://grasshopper.internal.dish.com/api
GRASSHOPPER_API_KEY=your_api_key_here

# DISH Internal Tools (optional - has defaults)
DISH_CART_URL=http://internal-tools.dish.com/cart
DISH_CCTOOLS_URL=http://internal-tools.dish.com/cctools
DISH_PORTAL_URL=http://internal-tools.dish.com/portal

# Google Drive (required for Google Drive search)
GOOGLE_DRIVE_API_KEY=your_google_drive_api_key

NOTE: Tools will work without API keys (will attempt anonymous access or return
error messages). Add API keys when you have them for authenticated access.
