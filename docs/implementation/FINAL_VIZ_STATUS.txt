## ISSUES IDENTIFIED AND FIXED

### ❌ → ✅ Issue 1: Token Metrics Stale (Always 0)
**Root Cause**: agent.py wasn't tracking tokens from LLM responses
**Fix**: Extract tokens from response.response_metadata.usage.total_tokens
**Location**: app/agent_mode/agent.py, lines 94-98
**Result**: Tokens now accumulate with each LLM call

### ❌ → ✅ Issue 2: Time Metrics Stale (Always 0)  
**Root Cause**: agent.py wasn't sending time metrics
**Fix**: Added interceptor.metric_update("time", llm_time)
**Location**: app/agent_mode/agent.py, line 100
**Result**: Time now accumulates with each LLM call

### ❌ → ✅ Issue 3: Metrics Replacing Instead of Accumulating
**Root Cause**: viz_router was doing metrics[key] = value (replace)
**Fix**: Changed to metrics[key] += value (accumulate)
**Location**: app/viz_router.py, lines 474-481
**Result**: Metrics properly cumulative across conversation

### ✅ Issue 4: Reasoning Graph
**Status**: Already working correctly
**No changes needed**: Nodes and links already being created properly

## TECHNICAL DETAILS

### Token Tracking Implementation
```python
if hasattr(response, "response_metadata"):
    token_usage = response.response_metadata.get("usage", {})
    total_tokens = token_usage.get("total_tokens", 0)
    if total_tokens > 0:
        interceptor.metric_update("tokens", total_tokens)
```

### Time Tracking Implementation
```python
llm_time = time.time() - start_time
interceptor.metric_update("time", llm_time)
```

### Accumulation Fix
```python
# Old (replaced):
metrics[event["metric"]] = event["value"]

# New (accumulates):
if metric_name in metrics:
    metrics[metric_name] += metric_value
else:
    metrics[metric_name] = metric_value
```
