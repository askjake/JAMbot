For each tool call, the visualization will show:

1. TOOL CALL EVENT
   - Tool name
   - Parameters (truncated for safety)
   - Timestamp
   - Elapsed time since conversation start

2. THOUGHT EVENT

   - Category: "tool"
   - Timestamp

3. RESULT EVENT (where applicable)
   - Result summary (e.g., "Found 5 results")

```
  timestamp: 2026-01-26T10:30:45
[TOOL RESULT] Command completed successfully
```

║                              TECHNICAL DETAILS                               ║
╚══════════════════════════════════════════════════════════════════════════════╝

HOW IT WORKS:

1. ThoughtInterceptor (app/agent_mode/thought_interceptor.py)
   - Singleton pattern, thread-safe
   - Background thread sends events to visualization server
   - Queue-based non-blocking architecture
   - Automatically enabled via environment variable

2. Tool Instrumentation
   - Each tool calls interceptor.tool_call() at start
   - Each tool calls interceptor.thought() for reasoning
   - Results logged with interceptor.tool_call(result=...)
   - Parameters truncated for safety (max 100-200 chars)

3. Visualization Server (app/agent_mode/ai_thought_viz_live.py)
   - Runs on port 5001
   - Receives events via HTTP POST to /api/event
   - Broadcasts to connected web clients via WebSocket
   - Real-time updates as events occur

4. Frontend (apps/chats/src/pages/AgentVisualization.tsx)
   - Embeds visualization server in iframe
   - Shows connection status
   - Provides instructions if server not running

  2. Network issues between app and viz server
