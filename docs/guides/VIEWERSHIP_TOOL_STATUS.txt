3. ROOT CAUSE IDENTIFIED: Lambda Web Adapter Issue
   ================================================
   
   The Lambda Function URL with RESPONSE_STREAM mode is wrapping the MCP
   server response incorrectly:
   
   Expected: Direct streaming SSE response
   Actual:   Wrapped in JSON with statusCode/body structure
   
   Response structure:
   {
     "statusCode": 200,
     "headers": {"content-type": "text/event-stream", ...},
     "body": "event: message\r\ndata: {...}\r\n\r\n",
     "isBase64Encoded": false
   }
   
   But the outer Content-Type is: application/octet-stream
   
   This breaks the MCP client which expects native SSE streaming.
