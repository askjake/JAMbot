# 🚀 Quick Start Guide

## 📦 Installation (5 minutes)

### Option 1: Automated Installation (Recommended)
```bash
cd /tmp/dish_chat_agent/log-monitor-app
bash install.sh
```

### Option 2: Manual Installation
```bash
cd /tmp/dish_chat_agent/log-monitor-app
pip3 install streamlit pandas plotly
```

## 🎯 Launch the Dashboard

### Step 1: Generate Sample Logs (Optional)
If you want to test with sample data:
```bash
# Terminal 1 - Generate continuous sample logs
python3 generate_sample_logs.py --continuous
```

### Step 2: Start the Dashboard
```bash
# Terminal 2 - Start Streamlit
streamlit run app.py
```

The dashboard will automatically open in your browser at `http://localhost:8501`

## 💡 Using with Real Logs

1. **Update the log file path** in the sidebar to your actual log file:
   - Default: `/home/montjac/dish-chat-logs/backend_8000.log`
   - Or any log file containing token statistics

2. **Configure settings**:
   - Refresh Interval: How often to check for new data (1-30 seconds)
   - Max Data Points: Number of messages to display (20-200)

3. **Monitor in real-time**: The dashboard will automatically update as new log entries appear

## 📊 What You'll See

### Top Metrics
- **Input Tokens**: Total tokens sent to the AI
- **Output Tokens**: Total tokens generated by the AI
- **Reasoning Tokens**: Tokens used for reasoning (if applicable)
- **Average Tokens/Message**: Mean token count per message

### Charts
1. **Token Usage Timeline**: See how token usage changes over time
2. **Token Distribution**: Compare input vs output vs reasoning tokens
3. **Cumulative Usage**: Track total token accumulation
4. **Message Type Distribution**: See the breakdown of agent/human/tool messages

### Data Table
View detailed information about recent messages including exact timestamps and token counts

## 🔧 Keyboard Shortcuts

- `Ctrl+C` in terminal: Stop the app
- Browser refresh (`F5`): Reload dashboard (state is preserved)
- `r` in browser: Rerun the app

## 📱 Access from Other Devices

If you want to access the dashboard from another machine on your network:

```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

Then access via: `http://YOUR_IP:8501`

## 🐛 Troubleshooting

### Dashboard shows "Waiting for data"
- Check that the log file path is correct
- Verify logs are being generated: `tail -f /path/to/your/log.log`
- Ensure log format matches expected patterns (see README.md)

### Port already in use
```bash
# Kill existing streamlit processes
pkill -f streamlit

# Or use a different port
streamlit run app.py --server.port 8502
```

### No charts appearing
- Wait a few seconds for data to accumulate
- Check that log entries contain token statistics
- Lower the refresh interval for more frequent updates
