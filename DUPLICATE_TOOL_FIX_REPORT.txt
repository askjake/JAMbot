Tool Registry Analysis:
-----------------------
From /home/jakebot/Jakes-agent/app/agent/agents/tools/registry.py

MCP tool sets are initialized at startup via initialize_mcp_tools():
  - _ASYNC_TOOL_FACTORIES maps tool set names to factory functions
  - Each factory calls get_mcp_tools(config_dict)
  - get_mcp_tools() creates MultiServerMCPClient and fetches tools

The "netra_mcp" tool set is backed by INTERNAL_TOOLS_MCP_CONFIG which is a
multi-server config containing BOTH jira_mcp and confluence_mcp.

When tools are assembled in agentic_rag.py:
  - get_tools_set("jira_mcp") returns 4 tools from standalone JIRA_MCP_CONFIG
  - get_tools_set("confluence_mcp") returns 3 tools from CONFLUENCE_MCP_CONFIG
  - get_tools_set("netra_mcp") returns 7 tools (4+3) from INTERNAL_TOOLS_MCP_CONFIG

This created a situation where tool names were added twice to the same list.

AWS Bedrock ConverseStream API requirement:
  - Tool names must be unique within a single request
  - Duplicate tool names trigger ValidationException
